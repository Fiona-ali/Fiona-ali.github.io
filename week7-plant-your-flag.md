## Analytics installed

The home page increments a Count API counter and shows the approximate home-page load count in the footer. It is a small public aggregate counter that needs no account or tracking ID. The key is public, so anyone who knows it can read or increment it; the count is not a verified unique-visitor measure and can include bots or repeat loads. It does not use cookies or a persistent visitor ID in the page code. Count API receives the normal network request needed to serve the counter.
