## First-impression feedback

**After ten seconds, what do I think Fiona does?**  
She is an AI/ML developer focused on computer vision and browser-based subject tracking.

**Would I believe she is good at it? What evidence supports that or is missing?**  
The portfolio's subject-tracking, Pac-Man, and vision-pipeline project descriptions point in a consistent direction. The original page weakened that impression by using unsubstantiated performance claims such as 30 FPS, low-light handling, and occlusion handling; it also showed subjective skill ratings without explaining their basis. The project artwork could be mistaken for a working demo, and the card had no direct path to more work or code.

## Feedback sort

### Must-fix
- State the specialization in plain words so a visitor can understand it quickly.
- Remove precise performance and robustness claims that the page does not substantiate.
- Present the hero-card list as focus areas rather than numeric-looking skill ratings.
- Label the card artwork as a visual preview, not as a live tracking status.
- Give interested visitors a working route to more project code.

### Nice-to-have
- Add a direct public repository or demo link for each project when the exact public URL is available.
- Add a short project case study with Fiona's role, one technical decision, and measured evidence.
- Add real project screenshots or a short demo capture in place of the decorative artwork.

## Changes made
- Rewrote the hero text to “AI/ML developer focused on computer vision” and a concise browser-based vision description.
- Replaced the pip ratings with the focus areas: computer vision, browser-based ML, Python/TensorFlow, and Java/React.
- Removed the unverified 30 FPS, low-light, and occlusion statements.
- Replaced the static “TRACKING ACTIVE” label with “VISUAL PROJECT PREVIEW.”
- Added a working link to Fiona's GitHub profile from the featured project card.

These changes were made to the live portfolio; project-specific proof links and real human feedback remain future additions. The supplied links and claims were not invented.
